Backend (.NET 10/C# API)

This folder is for the .NET 10 API backend. To create a new API project here:

```bash
cd backend
# create a web API project (interactive environment will vary)
# dotnet new webapi -n BackendApi
# dotnet restore
# dotnet build
```

Optional: To format C# code you can use `dotnet format` or configure an `.editorconfig` shared with the repo.
